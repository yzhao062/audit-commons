新增七项，修订一项

我们的资源目录现收录230项：新增七个用于记录、验证或规范智能体工作的工具，修订一篇论文的条目，无移除。

  • Tracekit：在智能体之外运行的签名进程，对被拦截的工具调用作出允许、拒绝或暂停以待人工批准的决定，并将每次运行签入可离线验证的 Ed25519 哈希链。绕过其钩子、适配器和网关的调用不会被记录；在默认开发模式下，被攻破的智能体可以接触到密钥。代码。
  • SealedRun：在智能体之外保管密钥的记录器，将经其代理的 LLM、MCP 和 A2A 调用以及 SDK 自报的步骤签入可离线验证的哈希链，并附带委托范围和人工批准检查。未经过记录器的步骤不会被记录；自报的步骤仍只是智能体自己的陈述。代码。
  • meilynx-verify：针对导出的 Meilynx 审计日志的离线验证器，检查哈希值、SHA-256 链、Ed25519 签名和 RFC 3161 时间戳，并报告第一处断裂。链完好并不能说明它是完整的。代码。
  • mnema：命令行工具和 MCP 服务器，将编码智能体的决策以带有 Ed25519 签名检查点的哈希链形式提交到代码仓库。它能显示篡改，但不能防止篡改：连同检查点一起删去最新事件不会被发现。代码。
  • deja-vu：本地命令行工具，为保存在磁盘上的编码智能体会话记录建立索引，默认按路径顺序取前十个改动文件，为每个文件列出最多三个编辑过或提及该文件的会话（这是文件层面的证据，不能证明改动出自该会话），并报告会话记录中的凭据。代码。
  • Agent Role Contracts：离线检查器，校验声明的智能体角色、任务范围、审查分离和交接。通过检查并不授予执行权限。代码。
  • Ponder：Node.js 命令行工具，将编码智能体的审查记录在仅追加的账本中，只要仍有已声明的单元未评分就拒绝结束；其收敛判定仅供参考。代码。

arXiv 2607.13304 的条目现采用修订版标题 Query Language Sensitivity in Automated Sentiment Scores of LLM Responses。修订版发现，其方差分解对是否纳入英语回答高度敏感；它没有识别出英语的因果效应，没有新增人工验证，并删去了此前关于品牌排名和查询预算的建议。论文。
