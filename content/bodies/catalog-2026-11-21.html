Three Additions

Our resource catalog now lists 237 entries: three tools for checking agent skills, agent runs, or the figures in agent reports, and no removals.

  • Ironheights: a local static scanner that grades agent skills and MCP server configurations and tool definitions before install and flags later changes as drift. Its README reports detecting about half of the malicious skills in one benchmark, and a clean grade is not proof of safety. Code.
  • agent-qa: a GUI-testing agent that records each step's planned action, served knowledge brief, outcome, screenshots, and console, network, and accessibility evidence, and sorts failures into causes for post-run diagnosis of its own runs. Source-available under FSL-1.1-ALv2. Code.
  • agentrecount: a command-line tool that recomputes numeric claims from an agent's report against the user's own tables, once a person or coding agent has encoded each claim in a CSV. Code.

Pull requests to the companion list proposed all three: #54 (pranshuchittora), merged November 16, and #61 (Frank-Masciopinto) and #62 (arsentev-ai), merged November 21. Each submitter is the project's author or owner. Maintainer edits narrowed the agent-qa entry to its recorded run evidence and described its source-available license, named the two kinds of MCP input that Ironheights grades, and stated that agentrecount needs claims encoded before it can recompute them.
