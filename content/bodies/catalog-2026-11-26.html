One Addition, One Removal

Our resource catalog still lists 237 entries: one tool for sealed, offline-verifiable decision records joins, and one tool whose repository is no longer available leaves.

  • Added: EPI (epi-recorder), which records one AI decision as a portable, signed file that a third party can check offline, with an optional customer-side witness log that flags records that differ from the reported version or were never reported. A plain warning exits with status 0, so pass or fail checks need the strict policy with the signing key pinned. Code.
  • Removed: OpenClaw Monitor, a dashboard for an OpenClaw gateway added on September 28. Its repository and its owner's GitHub account returned HTTP 404 on November 26, and no new home was found.

Pull request #64 to the companion list, submitted by EPI's maintainer, proposed the addition. It was merged on November 26 with maintainer edits that separate the entry from its neighbor and state what the witness log shows. The same merge removed OpenClaw Monitor from the list.
