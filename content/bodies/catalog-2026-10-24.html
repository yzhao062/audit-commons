Three Additions and One Removal

The October 24 catalog update leaves our resource catalog at 219 entries. It adds one tool, one specification, and one benchmark, and removes one tool whose source repository is no longer available. No other record changes.

  • solvi: a Python runtime in which a model proposes typed decisions and fixed checks, rules, and calibrated thresholds decide. Each step record is hashed and chained to the previous one, a replay recomputes every step from the recorded inputs, and a Guard component allows, denies, or escalates agent tool calls. Apache-2.0. Code.
  • VeritasChain Protocol (VCP): a finance-specific specification for tamper-evident records of algorithmic and AI-driven trading decisions, orders, executions, and risk controls, with JSON schemas and validation tests. A verified record does not show that the decision was correct or lawful, and the maintainer reports no external implementations or standards-body adoption. Version 1.2.0, CC BY 4.0. Specification.
  • AgentLeak: a benchmark for privacy leakage in multi-agent LLM runs that checks inter-agent messages and shared memory as well as final outputs. IEEE Access 2026. Paper, code.

The Praesidia audit verifier, added in the October 18 update, is removed because its repository at praesidia-ai/audit-verifier now returns a not-found error. It will return if the repository becomes public again.

solvi entered the companion list through a community pull request from its author. VCP and AgentLeak were proposed in issues by people involved in each project, who disclosed that involvement, and the list maintainer added them after review.
