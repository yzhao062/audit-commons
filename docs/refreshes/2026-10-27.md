[Issue #45](https://github.com/yzhao062/awesome-auditable-ai/issues/45) suggests agent-claimcheck, Andrii Boiko's Python toolkit that checks success claims in agent traces against tool receipts and state probes. At `9aba1ef`, an Agy unit found it working as documented, with offline tests passing except packaging tests needing the absent `uv` tool and one test failing only under `NO_COLOR`; current main, `57a609c`, adds only a README author link. Its 300-trace benchmark is synthetic, and transfer to real traces is untested.

The list maintainer also selected two new arXiv papers with public code, both Preprint 2026: V³AST-Bench ([arXiv:2610.35188](https://arxiv.org/abs/2610.35188)), a coding-agent safety benchmark with executable harm checks, and Concordat ([arXiv:2610.37461](https://arxiv.org/abs/2610.37461)), a pre-alpha library enforcing action protocols at run time.

Claude independently reviewed these three entries in two rounds. The list entry now carries those conditions; the Audit Commons catalog summary describes the protocol without the figure. Round 2 passed, and main was pushed as [4583670](https://github.com/yzhao062/awesome-auditable-ai/commit/4583670fdbe6aafd98543d48b4a3f26fda1e68f8). It passes the list's 57 tests and a strict audit of 320 link destinations (316 resolved, 142 title checks, no failures or warnings); its main CI passed.

The catalog is pinned to `4583670` with digest `766ad02ae9de5f74a4e756cc357e560585eeb0d40ebe54a28115001671636ad3`.
